\begin{abstract}
Current GUI visual-search models are usually evaluated as target-present grounding systems: given a screenshot and a target cue, they must produce a scanpath or target location. This forced-choice framing breaks down when the requested target is absent. We study target-absent GUI search with SeekUI and add post-hoc uncertainty-aware verification layers based on cognitive path evidence, OCR candidate evidence, and evidence-aware VLM judging. On a synthetic present/absent benchmark, SeekUI prompt-only absent F1 is 0.7300, while the evidence-aware VLM reaches 0.8981. On a manually reviewed 100-example realistic absent validation set, combined path+OCR verification improves absent F1 from 0.7907 to 0.9159. These results suggest that target-presence awareness is a necessary extension for GUI visual search.
\end{abstract}
