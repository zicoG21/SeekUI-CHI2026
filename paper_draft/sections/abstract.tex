\begin{abstract}
Current GUI visual-search models are usually evaluated as target-present grounding systems: given a screenshot and a target cue, they must produce a scanpath or target location. This forced-choice framing breaks down when the requested target is absent. We ask whether scanpath and UI evidence can help GUI visual-search models decide when to stop and report target absence, instead of forcing every query to ground to a UI element. We study this question with SeekUI by constructing a present/absent evaluation setting and adding post-hoc uncertainty-aware verification layers based on cognitive path evidence, OCR candidate evidence, and evidence-aware VLM judging. As the primary held-out result, combined path+OCR verification improves SeekUI absent F1 on an image-disjoint split from 0.7347 to 0.8804, with a positive bootstrap confidence interval. As a full-benchmark verifier comparison, evidence-aware VLM judging reaches 0.8981 absent F1. On a manually reviewed 100-example realistic absent validation set, combined path+OCR verification improves absent F1 from 0.7907 to 0.9159. These results suggest that target-presence awareness is a necessary extension for GUI visual search.
\end{abstract}
